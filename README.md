
```markdown
# YouTube Windy31ify

Шуточное расширение для Chrome, которое накладывает лицо Windy31 на все превью роликов на YouTube.

## Особенности
- Поддержка 17 различных изображений.
- Режим **ОРИГИНАЛ** (отображает только основное изображение).
- Возможность включения/выключения через всплывающее меню.
- Случайные эффекты: редкое появление секретного стикера, отзеркаливание по горизонтали и редкий переворот вверх ногами.

## Установка (для разработчиков)

1. Скачайте репозиторий в виде архива (Code -> Download ZIP) и распакуйте его.
2. Откройте Google Chrome и перейдите по адресу:
   ```text
   chrome://extensions/

```

3. Включите **«Режим разработчика»** в правом верхнем углу.
4. Нажмите **«Загрузить распакованное расширение»** (*Load unpacked*) и выберите папку с проектом.
5. Откройте YouTube и наслаждайтесь!

```

### Шаг 3. Загрузка через интерфейс GitHub (самый простой способ)

1. Войдите в свой аккаунт на [github.com](https://github.com).
2. Нажмите зеленый значок **«New»** (Создать новый репозиторий).
3. В поле **Repository name** укажите имя, например: `youtube-windy31ify`.
4. Сделайте его **Public** (Публичным).
5. Не ставьте галочки на «Add a README file» (он у вас уже готов).
6. Нажмите кнопку **«Create repository»**.
7. На открывшейся странице нажмите на ссылку **«uploading an existing file»** (загрузить существующие файлы).
8. Перетащите в окно браузера все файлы проекта:
* `manifest.json`
* `popup.html`
* `popup.js`
* `content.js`
* `icon.png`
* `README.md`
* папку `images/` со всеми картинками от `1.png` до `17.png`.


9. Внизу страницы в поле **Commit changes** введите `Initial commit` и нажмите зеленую кнопку **«Commit changes»**.

---

### Шаг 4. Добавление релиза (Release) для удобного скачивания

Чтобы пользователи могли скачать готовое расширение в один клик:

1. Сожмите вашу папку проекта в архив `.zip` (например, `windy31ify-v1.0.zip`).
2. В репозитории на GitHub справа найдите раздел **Releases** и нажмите **«Create a new release»**.
3. Укажите версию тега (например, `v1.0.0`) и заголовок релиза.
4. В блок загрузки файлов перетащите подготовленный `.zip`-архив.
5. Нажмите **«Publish release»**.
